# react-designapp context

Preserve existing unrelated changes. Headless Figma export lives in packages/react-designapp/src/renderToFigmaJSON.ts and shares buildTree/Yoga with Sketch. Figma JSON is REST-shaped with custom SVG/image payloads, not a native .fig file.

For live Figma work, read docs/figma-live/README.md and docs/figma-live/spec.md. The tools/figma-live environment now contains both the original probe and the initial live renderer/watch bridge under live/. Read docs/figma-live/usage.md before changing either. Use the Figma Plugin API and local transport; do not introduce Figma MCP. Use disposable Drafts and restrict mutation to the registered render root. Public identity props follow id > nativeID > legacy renderId. Anonymous live nodes use positional internal IDs, like unkeyed React children; do not claim those are durable through sibling insertion/reorder. Explicit IDs are required where durable cross-edit identity matters. Never match by native node names. Keep Figma-native IDs out of portable TSX/Loom source.

Document observed Figma version and selectors before relying on internal test IDs. Electron/CDP and automatic plugin launch were verified against Figma 126.9.11 with user-approved FIGMA_TEST=1; revalidate on app upgrades. Do not patch Figma binaries, fuses, authentication, or private application APIs to obtain automation. Treat unavailable desktop/authentication as a missing prerequisite and report it accurately. Existing Loom instructions apply to edits inside the separate loom repository; this spec does not authorize changing its compiler.
