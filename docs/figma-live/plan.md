# Implementation plan

1. **Validate launch environment — probe verified on 126.9.11.** Install/locate Desktop, create disposable Draft and stable development plugin ID. Probe CDP availability. Capture app version, visible UI and observed selectors. Automate plugin launch and require bridge acknowledgement. Acceptance: start from app open/plugin closed and reach ready without manual run. Native manifest picker automation may require macOS accessibility beyond Playwright.
2. **Prove persistence — single-frame probe verified.** Run provided frame probe, update width/name, stop and restart plugin, rerun probe. Acceptance: same native ID across updates and restart; duplicated provenance produces a diagnostic. First-time plugin registration and authentication remain explicit setup prerequisites.
3. **Adapt importer.** Review upstream license, pin source revision, factor create/apply operations and typed schema normalization. Acceptance: existing headless fixtures render with text runs, images, SVG, positioning and actionable errors; instance semantics are explicitly supported or rejected.
4. **Introduce durable identity.** Preserve identities through React/buildTree/export; distinguish declarations and occurrences. Acceptance: sibling insertion, reorder, rename, list-key reorder and component reuse preserve expected mappings. Coordinate Loom identity work separately under its repository instructions.
5. **Reconcile/hydrate.** Registry from node provenance; property reset, reorder, deletion, replacement, reconnect and duplicate detection. Acceptance: repeated identical snapshots create no extra nodes; compatible updates preserve IDs; foreign content survives.
6. **Watch/HMR transport.** Revisioned WebSocket, rebuild watcher, latest-state coalescing and diagnostics. Acceptance: rapid edits and font delays settle on latest revision; reconnect resumes without duplicates. Add Fast Refresh only if runtime state preservation is required.
7. **Reverse edits.** Baselines, property provenance and revision-checked AST patches for a limited writable subset. Acceptance: canvas text edit changes the correct literal, recompiles without echo loop; simultaneous conflicting source edit surfaces a conflict; computed geometry stays explicit.

Real-app assertions use plugin acknowledgements and native export/readback, rather than brittle canvas DOM inspection. Keep launch selectors in a versioned observed-selector file once discovered. Capture failures with screenshots and selector inventories locally; keep account details out of committed artifacts.

## Implementation update

The initial renderer now implements the supported headless schema directly, sharing the React/Yoga exporter. The external importer remains a research reference; its broader REST support and untyped silent property fallbacks were not copied. Explicit renderId/sourceId authoring, scoped metadata hydration, create/update/reorder/reparent/delete/type replacement, WebSocket watch updates and automatic registered-plugin launch are implemented under tools/figma-live/live. Unit tests cover duplicate identities and foreign-content preservation; the real-app fixture covers text, rich text, SVG, image, addition/deletion and restart. See usage.md for current limits and commands. Compiler-assigned identity and bidirectional AST patches remain deferred.
